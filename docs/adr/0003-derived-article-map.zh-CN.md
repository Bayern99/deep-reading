# 从印刷信号推导文章地图，审核语义判断

**状态：已接受**

文章地图记录一期内容的来源条目归属与版面位置。阅读遍先识别候选条目，并指出它们所属的准确印刷行或文本块。随后由确定性推导将这些答案绑定到主向量信号和印刷页面结构。

文章地图按可用情况记录 `id`、`type`、`section`、`start_page`、`all_pages`、印刷续接证据、标题来源、署名、媒体、段落和区域。它是翻译与编排所需的期号级输入，不是一份固定 ID 或预期数量清单。

## 决策

区分印刷事实与人工或模型判断。页面上的印刷标记能够提供字段时，就从标记推导。只有在内容归属或含义无法直接从印刷标记读取时，才交给阅读遍判断；不确定的判断必须标记供人工审核。

### 从印刷证据推导

- **`start_page`：** 包含条目首个正文块的页面。
- **`all_pages`：** 起始页加上印刷前向和后向标记指出的续接页。不得按标题相似度合并故事。
- **`section`：** 使用页面上印刷的栏目标题。印刷栏目缺失或有歧义时，应明确使用阅读遍判断并进行审核，不得猜测。
- **`continuation_evidence`：** 保留标记的 `line_id`、文本、页码和边界框，以便审计续接关系。
- **印刷页码到 PDF 页面：** 交叉匹配印刷的前向与后向标记。不要用手写的页码对照表替代。
- **标题和署名：** 将印刷标题和署名行保留为来源材料。栏目名、图片说明或页眉标题不会自动成为文章标题。

### 判断与审核

- **`type`：** 印刷版面可以缩小候选范围，但文章、短讯、图片说明、来信和其他阅读单元之间的区别需要语义判断。低置信度条目标记给人工审核。
- **阅读条目归属：** Agent 识别准确的行 ID 或文本块索引，并注明条目类型。答案必须绑定到提供的页面 bundle。
- **段落：** 确定条目所属行之后，再依据印刷缩进、字号和首字下沉推导段落起点（[ADR 0005](0005-paragraph-boundaries-from-printed-indents.zh-CN.md)）。
- **区域：** 保留区域及其来源、审核元数据作为可审计草稿。编译器不把单篇故事区域作为编译输入（[ADR 0004](0004-page-column-grid-not-story-regions.zh-CN.md)）。

## 考虑过的方案

- **无审核地生成所有字段：** 否决。印刷页面没有编码的含义和归属仍然需要判断，不确定情况必须显式呈现。
- **要求人工逐页重画所有印刷事实：** 否决。印刷标记已经为续接和页面位置等字段提供可审计证据。
- **只生成精简路由地图：** 否决。翻译与编排还需要段落、媒体、标题与署名来源以及版面位置证据。
- **按标题相似度推断续接关系：** 否决。印刷续接标记提供直接证据；相似度可能合并无关条目，也可能漏掉标题变化后的续接。

## 后果

- 每期都使用自己的阅读遍答案和向量页面生成文章地图草稿。条目数量和 ID 来自本期数据。
- 阅读遍是文章发现的语义依据，不是印刷事实的来源。推导过程会将答案绑定到页面，并捕获无效行、文本块和续接引用。
- 期号准备者在翻译和最终整理前审核有歧义的归属及所有 `needs_review` 标记。工具不得声称每个页面事实都经过模型独立核实。
- 没有编辑性阅读条目的页面也必须提供明确的空答案，以便区分“没有条目”和“Agent 没有作答”。
