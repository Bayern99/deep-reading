# Three-Tier Editorial Composition, Primary PDF Vector Signals, and Lightweight Portable Issue Artifact

Status: accepted

WSJ Deep Read runs as a lightweight CLI and Agent Skill (suitable for installation inside a cloud agent or bot VM) that takes a daily WSJ print PDF and its primary vector character stream (`native.json`) and emits a single, portable, self-contained HTML Issue Artifact (target 5–8 MB) with zero operator UI or pipeline audit chrome on the reader surface. Rather than relying on lossy secondary crops or maintaining a local Studio web server, persistent queue daemon, multi-version artifact database, and external `claim-evidence-v1` sidecar ledgers, every issue uses primary PDF vector/font signals to route items through a Three-Tier Editorial Hierarchy, backed by inline paragraph-scoped verification (`data-src="pK"`), declarative visual primitives (`<wsj-chart>`), native `Retina*` chart vector extraction, and a two-stage LQA funnel gate.

## Considered Options

- **Uniform deterministic template over pre-cropped secondary assets (First Issue Pilot approach)**: Rejected because skipping layout model calls eliminates editorial composition, dumps all figures before paragraph 1, chops chart headers (`p02-b78`), and discards lossless `Retina*` vector text in favor of noisy OCR and disclaimer banners.
- **Fixed JSON slot template for Tier 2 (Group B style)**: Rejected because fixed JSON slots produce repetitive, mechanical cards across articles instead of genre-conditioned typographic rhythm.
- **Model-authored raw SVG coordinates with external `claim-evidence-v1` sidecar mappings (Experiment 0)**: Rejected because hand-calculated SVG coordinates frequently clip text or distort scales, and requiring 70–150 external DOM-hash span bindings per article blocks automated generation or forces fallback to bare `<p>` tags.
- **Silent tier fallback on compilation errors**: Rejected because silently stripping diagrams or downgrading Tier 1/2 articles to plain text masks defects and degrades product quality.
- **Local Studio server with external asset directories or 200 MB base64 evidence bundles**: Rejected because cloud agent VMs need to deliver a single portable artifact directly to the reader, and 96% of the 210 MB pilot file came from embedding the raw PDF, 36 full-page PNGs, duplicate lossless figure encodings, and review logs that do not belong on the reader surface.

## Consequences

- **Primary PDF Font & Vector Extraction**: The pipeline reads the primary PDF character stream and Dow Jones proprietary font taxonomy (`ExchangeBook` for news prose, `DJ5Exchange-Medium` for opinion prose, `DJ5Escrow*` for headlines, and `RetinaMedium` / `RetinaBook` / `RetinaNarrowLight` / `RetinaMPNarrowLt` for printed chart titles, series labels, axis ticks, and sources). Printed charts are re-cropped from the original PDF using the union bounding box of the graphic and its adjacent `Retina*` title/source lines, eliminating chopped headers and OCR errors.
- **Print-Signal Curation & Composite Columns**: Physical PDF layout signals (page position A1/B1, multi-page jumps, length, figure density, and rubric type) deterministically classify items into Tier 1 (5–8 flagship stories), Tier 2 (~45–50 standard articles/analyses/opinions/reviews), and Tier 3 (compact digests/briefs/tables), while grouping single-paragraph same-page fragments (`Letters`, `Stock Spotlight`, `U.S./World Watch`, `Corrections`) into cohesive Composite Columns (~62 reading units per issue).
- **Sub-Mode Tier 1 & Genre-Aware Tier 2**: Tier 1 distinguishes figure-light mechanism/financial stories (which receive Declarative Visual Primitives compiled into custom SVGs) from photo-rich documentary features (which receive magazine-style choreography of original figures anchored at their natural `after pK` narrative positions computed from PDF $(x, y)$ coordinates). Tier 2 adapts its typographic grammar by genre (`article/analysis` takeaway bullets + data highlights; `opinion/editorial` thesis box + pull quotes; `review` work metadata card + literary pacing; `sidebar` linked to parent story).
- **Declarative Visual Primitives & AST Surgical Completion (Zero Silent Fallback)**: Models express charts and mechanism flows via compact `<wsj-chart data-src="pK">` primitives (~8 lines); the compiler verifies all numbers against paragraph `pK` and deterministically renders responsive, clip-free WSJ SVGs. Missing narrative anchors are surgically inserted in the `lxml` AST; any remaining factual mismatch triggers a micro-node repair on just the offending element or fails fast—never silently downgrading tiers.
- **Chart Companions & Clean Bilingual Reader Shell**: Original printed WSJ charts are anchored at their narrative paragraph position in WebP format and paired with a bilingual Chart Companion card grounded in lossless `Retina*` vector strings and `data-src="pK"`. The outer Reader Shell owns the 7-section navigation, `What's News` deep links, and `中文 / EN / 双语` switching (where `双语` pairs main narrative prose while keeping SVG internal labels and micro-controls single-language to prevent geometry overflow).
