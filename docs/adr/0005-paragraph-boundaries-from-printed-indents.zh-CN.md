# 从印刷缩进与字号识别段落边界

**状态：已接受**

本决策解决 [ADR 0004](0004-page-column-grid-not-story-regions.zh-CN.md) 留下的段落位置问题。段落位置（`native_regions`）以印刷证据为依据并可确定性推导。阅读遍提供条目的行或文本块归属，但不判断每段从哪里开始。

## 背景

候选信号包括首行缩进、额外行距，以及要求阅读遍识别每个段落。额外间距并不可靠，因为段落间距可能与正常行距相同。让阅读遍额外判断段落起点，会给已有条目归属任务增加另一项语义工作，而且仍然需要印刷证据校验。

## 决策

一个段落由重建后的连续印刷行构成，直到遇到下一个印刷起点。使用以下信号：

- **首行缩进：** 从*正文局部边缘*起 6–20pt。局部边缘取同一栏此前五条印刷行的最小左边界，而不是页面网格起点。图片绕排或嵌套分栏可能在页面中途缩窄正文宽度；大于 20pt 的偏移可能来自绕排，并非新段落。
- **小标题字号：** 10–16pt。小标题本身是独立段落。小标题之后的正文即使首行没有缩进，也从新段落开始。
- **首字下沉：** 大于 20pt 的单个大写字母开启新段落。
- **排除非叙事行：** 15pt 及以上的展示字号、署名（`BY …`）、`RetinaCondensed*` 栏目标签、续接标记，以及阅读遍按文本块提供时的条目标题或副标题。只有印刷后向标记与展示字体信号相互吻合时，才排除续接页重复标题。每一页都重新开始检查。

识别段落起点前，先重建印刷行。同一基线上的文字片段在同一印刷栏时组成一条行。根据栏内容范围判断归属；右侧边缘的片段只有实际进入下一栏的印刷范围时，才属于下一栏。

字体角色可以辅助校验：正文族包括 `Exchange*`、`DJ5*` 和 `RetinaBook`；`RetinaLight` 副标题和 `RetinaCondensed*` 栏目标签不属于叙事正文。不要用额外行距识别段落起点。

## 考虑过的方案

- **要求阅读遍给出段落边界：** 否决。语义判断不应取代印刷信号，错误答案也缺少第二重校验。
- **使用额外行距：** 否决。段落间距与普通行距可能无法区分。
- **把人工编写的段落 ID 作为工具输入：** 否决。新的外部期号工作区必须能够从印刷行推导自己的段落 ID。

## 后果

- 合成示例：新段落首行从正文局部边缘向内约 10pt 时，它是段落起点候选；25pt 的偏移不符合本规则。
- 五行局部边缘窗口是规则的一部分。图片绕排或嵌套分栏若超出该局部窗口，可能混淆段落边界；版面改变行宽时应检查推导出的段落框。
- 每个推导段落都保留页码、栏位和边界框证据，供编译器按实际印刷顺序排列段落和锚定图片。
- 阅读遍推导的段落在其来源行正确绑定前都属于草稿。最终编排使用已批准的期号单元。
