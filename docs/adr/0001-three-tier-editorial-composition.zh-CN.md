# 基于 PDF 主向量信号的三层编辑编排

**状态：已接受**

WSJ 深读是一套可复用的命令行工具与 Agent 工作流。它使用用户提供的印刷版 PDF 和外部期号工作区，生成一份便携、自包含的 HTML 整期交付制品。工作区提供本期元数据、文章清单、已审核双语段落、印刷证据和编辑决策；工具本身提供可复用规则与编译器。

产品流程读取 PDF 主向量与字体信号，按三层编辑体系处理条目，使每项编辑干预都以来源段落为依据，提取印刷图表向量，运行双阶段 LQA 漏斗，并输出一份不带操作界面的 HTML 制品。

## 决策

**使用主向量信号和三个不同的编辑层级。** 已批准叙事保存在期号数据中，编辑内容通过 `data-src="p2"` 或 `data-ref` 绑定段落 ID。模型编写的图表使用 `<wsj-chart data-src="p2">` 之类的语义标记；编译器检查来源依据并渲染图形。直接引语必须在其引用语言中逐字保留。

各层级的定义如下：

- **Tier 1 — 深度精编：** 为选定的头条和专题提供完整编辑设计。根据报道内容选择叙事节奏、原图编排或声明式视觉图解。法医卷宗是适用于调查和机制类报道的一种编排文法。
- **Tier 2 — 轻量排版精编：** 为标准稿、分析、意见和书评提供符合体裁的排版处理。要点、论点盒、小标题、重点强调、引语和作品元数据都是候选方式，不是必须填充的栏位。
- **Tier 3 — 紧凑功能版式：** 克制地呈现短讯、摘要、更正、来信和只读表格，不使用旗舰文章头部，也不添加多余的叙事设计。

Agent 在选择不干预、文字处理、版式变化或阅读辅助前，必须通读整条内容。比较读者收益与重复内容、空间和阅读顺序方面的代价。保持原文不动是有效结果；组件数量不是质量指标。

## 考虑过的方案

- **基于二次裁图的统一确定模板：** 否决。它会取消编辑编排，可能把图片全部放在正文之前，也可能截断图表标题，并让 OCR 文本取代原始向量成为权威来源。
- **为每篇 Tier 2 固定 JSON 栏位：** 否决。固定栏位会生成重复卡片，并把有依据的编辑处理误成必须填满的内容。
- **由模型编写原始 SVG 坐标和外部主张台账：** 否决。手算坐标可能裁切文字或扭曲比例；维护大量外部文本片段绑定会使日常工作脆弱。语义原语让编译器负责几何布局和校验。
- **编译失败时静默降级：** 否决。删除图解或将文章降为纯文本会掩盖缺陷并降低阅读质量。如果来源明确，就修复最小出错节点；否则给出具体错误并停止。
- **使用本地工作台、外部资源目录或嵌入证据包：** 否决。读者收到一份便携 HTML 制品；来源 PDF、提取证据和审核报告留在外部期号工作区。

## 后果

- **从来源 PDF 提取。** 读取 PDF 字符流和字体角色。印刷图表从原始 PDF 裁取，合并图形与相邻 `Retina*` 标题、来源行的范围。这样保留图表标签，不会把 OCR 或既有裁图当成权威依据。
- **依据版面证据路由。** 依据印刷显著度、栏目、篇幅和图片密度选择层级。若读者实际按同一栏目阅读，可将同页短条目合并为复合专栏。每期的数量和成员都由本期数据决定。
- **让体裁与证据决定 Tier 1 和 Tier 2 的处理。** 图像较少的机制稿可使用声明式图解；图片丰富的专题可在自然的 `after pK` 阅读位置插入原图。Tier 2 根据体裁选择文法：分析稿要点、意见稿论点与直接引语、书评作品卡，或关联母篇的侧栏。只采用内容支持的处理。
- **按段落范围校验。** 编辑内容中的数字必须出现在声明的来源段落中。合成示例：如果 `p2` 写车队有 120 辆公交车，绑定到 `p2` 的模块可以呈现该数字；不能从其他地方添加预测数据。
- **小范围修复，否则失败。** 如果来源明确，编译器可以在 HTML 树中补入缺失的叙事锚点，并重试具体的事实节点。它不会静默删除必要层级或编造替代内容。
- **为原始图表配简明双语说明。** 按实际印刷顺序锚定 WebP 原图，并将图表伴读卡绑定到相同图表向量和引用正文。图表标签来自 `Retina*` 向量，不来自 OCR。
- **保持阅读界面干净。** 阅读器负责七个规范栏目、期号概览、沉浸式阅读和中文 / 英文 / 双语切换。双语模式配对呈现正文；若配对会破坏几何布局，SVG 标签和微控件则保持单语言。报告和来源证据留在 HTML 之外。
