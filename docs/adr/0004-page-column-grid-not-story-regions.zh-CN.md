# 编排依据页面分栏网格，而非单篇故事区域

**状态：已接受**

本决策细化 [ADR 0003](0003-derived-article-map.zh-CN.md)：页面分栏网格是印刷页面的属性；单篇故事具体占据哪些栏位未必直接印在版面上。

侧栏、子篇或短条目可能与主篇共享同一横向版带。猜测故事区域可能打乱文本顺序，或把图片放到错误位置。这些是读者可见的错误，不是无害的诊断信息。

## 决策

编译器使用从页面印刷向量线推导出的分栏网格。根据页面网格和元素的水平位置计算栏目序号。单篇故事的 `regions` 作为草稿记录保留，并带有 `regions_source` 和 `needs_review`；它们永远不作为编译输入。

## 考虑过的方案

- **推断每篇故事的确切栏位集合：** 否决作为编译输入。当多个条目共享页面版带时，故事归属可能有歧义；若每篇都要求人工逐行阅读，就无法实现确定性复用。
- **接受近似的单篇区域：** 否决。错误栏位会悄悄改变实际阅读顺序和图片位置。
- **删除 `regions`：** 否决。区域作为可审计草稿仍有用，也可以由阅读遍补充。它们只是不具备编译权威性。

## 后果

- 页面分栏网格决定页面中的段落与图片顺序。编译器使用印刷行的几何位置确定栏目，不使用故事边界框。
- `regions` 与 `regions_source` 说明已知位置及其来源。`needs_review` 标明尚未解决的归属。下游不得把这些字段当作编译契约。
- 段落级原生位置（`native_regions`）仍可用于锚定编辑内容和图片。它依据所属印刷行与段落边界推导，不从故事矩形框中猜测。
- 不要恢复精确区域编译门槛。未来若某种版式需要故事所属区域，应先定义独立的证据规则和人工审核边界。
