# 设计说明 · WSJ 深读 R3.3（oil-ui 润色轮）

## 用户任务
《华尔街日报》每日深读的长文阅读页。当前是 R3.3 样稿，含两篇样章：
E1-005 沙特长文（P1 必读）、E3-002 电动车数据报道（P2 重点）。

## 主动作
阅读。中文为主，一键切英文对照。

## 设计北极星
中文报纸的印刷质感，朱砂作批注——像一份被编辑用红笔圈点过的深度阅读样张。

## 选定方向（沿用，不重探）
- 方向 A · 朱砂印刷风：朱砂 #cf421b 作强调（关键数字/引文/时间线），石油青 #14616a 作结构
- 暖纸底 #faf6ec、零圆角、粗黑线分隔
- 字体：正文黑体 Noto Sans SC 16.5px/1.95；标题/引文/数字/首字下沉用 Noto Serif SC 900
- Vercel Web Interface Guidelines 已合规（focus 环、44px 触摸目标、scroll-driven reveals、text-wrap:pretty 等 12 项）

## 硬性约束（评审不可动）
1. 中文正文逐字来自校订稿，一字不许改
2. 中英 1:1 双语，EN 按钮切换
3. 图片宁缺毋滥：只用充电站实拍 + B1 原图表（糊图已撤）
4. 双色语义分工：朱砂=强调/警示，石油青=结构/数据；不只靠颜色传达状态（有文字标签）
5. 页脚须诚实：标明编辑绘制的图表、图片来源

## 设备
手机 390 为主（用户在 iOS 上审稿），桌面 1440，超宽 2560。

## 验收重点
- 首屏三秒：认得出是"报纸深读"，不是通用模板
- 长页节奏：两篇文章各有起伏，不只看首屏
- 中文断行：无孤字、无数字单位被拆散
- 200% 下关键区域不重叠

## R3.4 oil-ui 评审修订（2026-10-13）
独立评审（存量润色评审，一轮不打分）4 条已修：
1. byline 大小写统一为全大写（CSS text-transform，不动内容）

3. 桌面端"关键数字"四列底部对齐（flex column + 说明 margin-top:auto）

评审"保留"项：朱砂单侧批注语言（图注竖线/时间线圆点/引文大引号）+ "只给最关键一处朱砂"的克制——只加强对齐一致性，不磨掉。
评审其他观察（石油青未进数字条）：维持现状——克制即语言成立的关键，不为用色而用色。

## R3.5 组件信息层级（2026-10-13 Jerry 批评"不符合基本原理"后重做）
原则：每个组件一眼认出最重要的信息；题眼不能比内容轻；新事实压过旧说法；数据是主角。
- 组件题眼 cmp-label：mono 700 13px 墨色（原来 11px 弱灰，倒置）
- 主张与现实：左"此前称"退（serif 400 15px 次黑），右"随后发生"进（serif 700 20px 墨 + 朱砂"至少12人死亡"）
- 柱状图：行标签拆时间（弱）/判断词（墨 800，如"峰值/徘徊"）；数值 mono 800 22px 朱砂不折行
- 反差表：修好从没命中过的表头选择器——左"电动汽车销量"朱砂（警示/衰退）、右"充电基础设施"石油青（数据/增长）；左栏正文次黑退后，右栏正文墨色 + 关键数据石油青
- 对比度：弱灰 ink-3 在纸上 5.8:1（原来 3.1:1，不及格）

## R3.5-hotfix（2026-10-13 Jerry 拍桌子）
- 去掉正文 text-wrap:pretty：这条是 R3.3 从 Vercel guideline 抄来的，拉丁文防孤儿行专用；对中文它会硬把段落掰成等长短行，手机上右边空出一大块。教训：抄 guideline 先想想适不适合中文。
- 主张与现实左侧回到 600 16px 墨色：之前压成 400 15px 次黑看起来像坏了，不是"退后"。退后靠右侧更大更重 + 朱砂来体现，不靠把左侧弄残。

## R3.5-fix2 反差表重做（2026-10-13 Jerry："是为了组件而组件吗"）
- 病因：表头行与内容行脱钩，手机堆叠后读者分不清谁跟谁；朱砂/石油青表头 + 灰黑交替 + 石油青高亮，多种强调同时抢注意力。
- 改法：配对块结构——每个事实自带小标签（电动汽车销量/充电基础设施），标签贴着内容走；颜色只剩弱灰标签 + 墨色正文；配对靠位置和分隔线，不靠颜色。桌面仍两栏，手机堆叠不断裂。
