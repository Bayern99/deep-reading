# Layout Pattern 决策规范 v1.0（Planner 自主选择用）

## L02 正文与边注

**叙事关系**：边注是主线的"旁白"——解释术语/身份/背景，不推进叙事。
**适用**：①术语/机构/人物首次出现且不解释会影响理解；②正文只给名称未给定义（如 Polymarket）；③边注内容可公开验证、无争议。
**拒绝**：①正文已解释；②需要长篇解释（>80字）；③边注与锚点段无直接关联；④人物/术语只出现一次。
**证据**：锚点段落 ID + 边注事实来源（公开可验证）；editorial_added=true。
**手机顺序**：锚点段 → 边注（inline）→ 下一段。边注不得提前泄露后文。

## L03 平行双栏比较

**叙事关系**：两组信息是"天平的两端"——读者需要逐项对照才能理解差异。
**适用**：①原文明确给出两组在相同维度上的成对数据（如 375mph vs 拦截能力；55% vs 90%）；②维度≥2 且 ≤4；③对照关系是原文的论证结构，不是编辑拼凑。
**拒绝**：①维度不对等（A有3项B只有1项）；②只是先后发生而非对比；③任一维度数据缺失需脑补；④含长连续正文（>100字/项）。
**证据**：成对维度列表 + 每项原文锚点；缺失值必须标"原文未给"。
**手机顺序**：维度1→A→B → 维度2→A→B（交替纵排，不跨屏回忆）。

## L05 图文并置

**叙事关系**：图是"证据"，文是"解说"——图证明文所说的事正在发生。
**适用**：①照片/图表与紧邻段落讲同一事件；②图注归属可靠；③图不解释文就缺证据感。
**拒绝**：①图与文无直接关联；②图注归属存疑；③图只是装饰。
**证据**：asset_id + 图注 + credit + 锚点段落 ID。
**手机顺序**：图 → 图注（含 credit）→ 解释文。

## L08 跨栏图形

**叙事关系**：图是"核心证据"，值得打破正文宽度。
**适用**：①图表/数据表是原文论证的核心；②640px 内标签挤压不可读；③原始图完整可验证。
**拒绝**：①装饰性大图；②数据不完整；③OCR 轴标签残缺。
**证据**：原始 asset + 数据来源 + 单位/时间范围。
**手机顺序**：图（min-width 560px 横滑）→ 来源 → 正文。不得压扁至不可读。

## 通用拒绝（所有 Layout）

- 为展示组件而制造机会
- 破坏原文叙事顺序
- 同一位置叠加多个布局
- 移动端阅读顺序错乱
